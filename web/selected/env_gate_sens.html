主升精选 · 环境门控结论的样本量敏感性检验

一次密扫描 step=3（243,121 行 / 96 个信号日）→ 派生 3 组步长。横截面分位是日内计算的，所以从密扫描里抽日期子集与直接按该步长扫描严格同结果；显著性 = 按日 block bootstrap 800 次。
要回答的问题：主升精选已上线的二值门控（强势开仓、其余空仓），强势档 edge 原来只由 8 个信号日撑着。这么少的样本，结论是「效应真实但被低估」，还是「小样本噪声」？

对已上线二值门控的影响： 「强势开仓」跨步长稳定成立（四组步长下绝对收益均为正），这条保留。 「弱势空仓」跨步长稳定为负，这条有依据。 但「震荡、破位」档的绝对收益符号随采样步长翻转（换一组采样日期就变号），说明原证据页给出的负值并非稳定效应。按红线：这两档的正确定性是「不可判」 —— 生产上仍按「宁可不选」空仓，但那是纪律而非数据结论，页面上不能写成「数据证明该档该空仓」。

局限

  • 派生子集与直接扫描同结果，前提是横截面分位只在该信号日内计算（本项目满足）；若将来改成跨日面板打分，本页的「一次扫描派生多组」做法就失效。
  • 样本量放大只能检验采样密度，不能凭空造出新信息 —— 相邻信号日的前向窗口仍是重叠的，所以 step=3 的有效样本量并不等于独立观测数，block bootstrap 已按日整块重抽来处理这一点。
  • 本页只做检验，不改生产；二值门控是否保留由 selected/env_gate.html 的证据决定。
  • 结果落 quant/_env_gate_sens.json；种子固定 20261003。
