量化策略板 · 方法论 Playbook

综合选股 + 买卖点操作建议，按短 / 中 / 长 持有周期组织。本页是常驻方法论；选股能力与局限以各池实验室页为准。
定位：综合视图，不是新 alpha 源。本板把已在样本外证实的各池因子族（趋势 / 资金 / 反转 / 做T / 增仓） 重新组织成「短线 / 中线 / 长线」三种持有周期视角，并各自给出买区 / 止损 / 目标 / 盈亏比。 它解决的是「这只票该用哪种打法、拿多久」，不宣称叠加胜率——三族分是同一批真实日K的不同切角。

一、六套量化策略来源

策略族来源池 / 实验室在综合板里的角色
趋势主升精选 lab（全市场域 9 因子）中线族主体：近20/60日动量、站上MA60、MA20斜率、均线多头、接近近20日高
资金主升精选 lab（上涨放量占比 / 量能放大 / 回调缩量）短线+中线族的动量确认；离线源用价量代理（历史主力净流入不可得）

二、短 / 中 / 长 三族因子（先验固定，等权横截面分位）

周期因子（方向由经济逻辑给定）排序含义
短线5日动量 + 量比 + 贴近MA10 + 箱体窄(近10日振幅std) + 上涨放量占比活跃、贴线、箱体紧凑 → 适合做T/波段
中线近20/60日动量 + 站上MA60 + MA20斜率 + 均线多头 + 接近近20日高趋势已转多、资金进场 → 回踩低吸吃主升
长线低波动(ATR%) + 距52周高深跌回撤 + 底部锚定/增仓低位 + 低波动 + 底部确认 → 逢低布局价值修复
每个因子在当日全市场可交易域（剔 ST/退、20日均额≥3000万、现价≥2元、K线≥250日）内做横截面分位， 方向乘权重（均 +1，越高越好）后等权合成该族分。三族分各自 0~100。不筛因子、不按回测调权重——这是干净样本外的前提。

三、持有周期怎么定

对每只入池票，取三族分的最高一族作为它的持有周期标签；再加两条经济门控：
  • 中线须趋势 intact：若未站上 MA60，则取消中线资格，改判短/长。
  • 短线须可交易：若 20 日 ATR% 过低（<0.8%，近乎无波动），则取消短线资格，改判中/长。
标签只说明「这只票最贴合哪种打法」，不是推荐。

四、买卖点怎么算（量化，非预测）

周期买区结构位止损目标
短线近10日箱体下沿×1.00~1.02（贴近下沿低吸，不追高）近10日低×0.97（破位先减半）近10日高×1.00 / ×1.04
中线回踩 MA10/MA20（min×0.99 ~ max×1.01）近20日低×0.97近20日高×1.05 / ×1.10
长线底部锚定：谷底×1.00~1.03（或阶段低位）谷底×0.97（结构失效位）本轮下跌段回撤：谷底+跌幅×0.382 / ×0.618
盈亏比 RR = (T1 − 买区上沿) / (买区上沿 − 止损)。箱体位置 = 现价在「止损位(0%)→买区→T1→T2(100%)」中的百分比， 用于判断「买区内·可买 / 持有·待涨 / 已到T1/T2 / 已破止损」。

五、环境只控 β（仓位系数），不改排序

大盘环境（由上证近20日偏离 + 广度等判定）只输出仓位系数（破位 0.0 / 弱势 0.55 / 震荡 0.8 / 偏强 1.0）： 用它给「该拿多少」，不用它改「选哪只」。 短线做T方向须与环境配对（弱环境做反T、强环境做正T），反向配对是全表最差档——这是做T池 lab 的实证结论。 宁可降低仓位也不降低确定性；环境差就空仓等待。

六、退出纪律（唯一跨期稳定的改进）

① 两层止损：结构位（近20日基底 / 箱体下沿 / 谷底×0.97）破位先减半，跌到更宽固定位（约 −15%）再全出； ② 移动止盈：浮盈达标后止损上移跟踪，到 T1/T2 先兑现一半；③ 胜率与单笔均值是一对权衡，不要只看胜率。 入场侧（选股）两半常反向，退出侧两半同向——所以「退出纪律 > 入场筛选」是铁律。

七、期间依赖诚实披露

各池样本外实证均显示 edge 随市场环境摆动：例如反转池 half_oos 切分下训练半 −3.0pp、测试半 +16.4pp， 逐月 edge 在 −7.7pp ~ +25.4pp 之间摆动（4 负 5 正）。本板不掩饰该波动；某期很强不代表下一期也强， 环境状态从「提高 alpha 的手段」降级为「只控 β 暴露的仓位系数」。

八、局限

① 前向窗口重叠 → 样本非独立；② 样本约 10 个月，换年份是否成立无法验证； ③ 主力资金用「上涨放量占比」价量代理（离线源历史主力净流入不可得），选股日可叠加真实主力净流入作加分； ④ 长线底部锚定依赖 rev/bottom_state.json（本地累积、随日K刷新）； ⑤ 绝对胜率含 beta，结论以相对口径（个股前向收益 > 同期同池等权中位数）为主。
