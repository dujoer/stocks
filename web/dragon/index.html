四、胜率最高的形态（这一节的全部数字都是现算的）

形态 = 「退潮期 · 五板」，意思是：市场情绪判定为退潮、当天收盘封涨停、连板数正好是 五板（就是这只票连续第 N 个涨停，N 即上面的板数）时，以当日收盘价买入、往后持有 K 天的胜率。这就是当前阶段（今天判定为 退潮）的最优形态。
本节样本期：2023-07-18 ~ 2026-10-08，共 780 个交易日（日K 来源 _long_kline）。样本期越长，这类统计越不容易是运气 ——但同时也意味着横跨了完全不同的几段行情，别把整个样本期的平均值当成今天的预期。

  • ① 随机对照：同一天、同等数量，从全市场任意股票里随机抽 200 次，K=1 胜率的 95 分位是 47.8%（中位数 46.5%）；这一形态是 57.0% —— 过了（固定种子，可复现）
  • ② 同阶段对照：同一个情绪阶段里，全部涨停票的 K=1 胜率是 55.9%，这一形态是 57.0%，超额 +1.1pp —— 说明不是「阶段本身在托底」。

第④道「退出可兑现」已补做，见第六节。
看胜率的同时必须看「中位」和「最差」：K=5 均值 +0.72% 但中位只有 -5.66%、最好 +61.08%、最差 -43.94%。
意思是：多数时候赚的就是这点中位收益，真正把均值拉高的那批（最好那只 +61.08%）不是常态 —— 拿均值当预期收益会高估自己。最差那一列才是仓位管理的依据。

归因

可核的部分（数据直接给出的）：
  • 该形态 K=1 胜率 57.0%，比同阶段全部涨停票（55.9%）高 +1.1pp，比同天全市场随机抽票的 95 分位（47.8%）高 +9.2pp。
  • 样本 93 个、横跨 67 个交易日 —— 不是撞在单日上的偶然。
  • 三个持有期（1 / 3 / 5）都优于各自对照，不是只在某一个持有期上亮眼。
不可核的部分（如实标注，不编）：它为什么涨、题材是不是真的、游资在不在里面、明天会不会直接一字开 —— 这些本地数据衡量不了。日K 只能告诉你「过去这个形态后续大概率涨」，不能告诉你「这次为什么涨」。任何把行情归因到某条消息、某个概念的说法，都请自己核，本页不代劳。

三点得一起读：① 「无止损」是极端假设、不是可执行规则 —— 回撤全留给你（单笔最差到 −40% 量级），均值略好不等于能用；② 有 9 格是一致地「放宽更差」，对这些形态，「−5% 太近」这个说法本身就错了；③ 即便「两段都变好」的那 3 格，放宽后的绝对净收益大多仍是负的。另外前半段与后半段的整体水平差得很远（同一格能差好几个点），说明结论强烈依赖行情区间，这本身就是「不可依赖」的证据。
所以：不许拿「放宽止损」去救这套规则。这条根因假设已被跨窗口检验证伪。真要换退出规则，必须重新走 walk-forward + 随机对照，而不是在这份数据上把档位调一调 —— 那正是红线要拦的「挑最好看的那个」。

附加检验 B：换成项目本来就在用的移动止盈，能不能救？

这次换的不是我临时拍的线，是项目里唯一那套退出实现
  • 出场：_exit_sim.py 的移动止盈 —— 硬止损 −12%、涨到 +6% 激活、从最高点回撤 3% 走人、最长持有 20 个交易日。这是生产参数，固定一个档位、不做扫描（上一轮已经证明「在这份数据上把参数调一调」是幻觉）。
  • 成交假设：可实现口径（保守日内 + 跳空成交）；入场用 T+1 开盘价，T+1 一字封板买不进的样本剔除并计数。
  • 对照基线：同一情绪阶段的全部涨停票，用完全相同的退出与成交假设算 ——两边口径不一致就是拿假超额。
结论：换退出确实把「几乎全负」拉回来了一些，但仍然不成立。24 个可判格里 4 格过了相对判据（胜率高于同阶段基线），扣掉 0.2% 双边成本后净均值为正的只剩 0 格。

以下是纸面推导（第④道通过之前，只当记录看）

这条方案是这么推出来的
  • 触发：情绪阶段判定 = 退潮，且当日收盘封涨停、连板数 = 五板。两条同时满足才进名单。
  • 买入假设：以当日收盘价成交。⚠ 这是简化假设 —— 真实打板要排队，可能封不上、也可能高开走，实际成交价高于收盘价；本页所有胜率都建立在「能成交且成交在收盘价」上，这一条没有单独验证。
  • 持有期：K=1（这个形态在该口径上均值 +1.68%、胜率 57.0%）。K=1 胜率更高（57.0%）但 均值只有 +1.68%，属于快进快出；两种口径差别很大，别混着用。
  • 仓位上限（由历史最坏情况反推，不是拍的）：本形态 K=5 的最差是 −43.94%。按单笔亏损不超过本金 1.5% 的纪律，单票仓位 ≤ 3.4%（换成 K=1 口径，最差 −10.92% → 单票 ≤ 13.7%）。取更小的那个。
  • 退出：跌破买入价 5%（由 K=1 最差的一半反推）减半，继续跌破再走；或持有满 1 个交易日时间止损；或情绪阶段转退潮 / 高潮时了结 —— 三选先到者。⚠ 这条线是从历史极值推的保守线，不是优化出来的最优解；第④道实测下来，正是这条线把胜率吃掉的。
  • 明确不做：冰点期去做首板 / 二板（K=1 胜率 55.1% / 55.7%，基本就是扔硬币，超额接近 0）。
结论：这一节的东西现在不能执行。四道自检里 ①②③ 已过（无未来函数 / walk-forward / 随机对照），第 ④ 道「退出可兑现」的结果是：第④道「退出可兑现」过了相对判据 —— 可实现口径胜率只比同阶段基线高0.4pp（这个量级属噪音），但扣掉双边成本后净均值仍为负：所以它仍然不是一条能执行的规则，只是「比乱买略好一点」。
而且这不是某一个形态的问题：把 4 阶段 × 6 连板桶全过一遍，24 格里扣成本后净均值为正的有 0 格。
而且这不是某一个形态的问题：把 4 阶段 × 6 连板桶全过一遍，24 格里扣成本后净均值为正的有 0 格；再把退出换成项目本来就在用的移动止盈（_exit_sim.py），24 格里净均值为正的也只有 0 格。同时「是不是 −5% 止损太近」这条根因假设已被跨窗口检验证伪（放宽止损在前/后半段大量反号，见上面「附加检验」）。所以问题出在这套打法本身（买涨停票 + 固定持有期/止盈），不是「形态选错了」，也不是「调一个参数能救」。真要翻案，必须换一个入场逻辑重新走 walk-forward + 随机对照，不能拿这份数据现挑。
模拟口径与 `_exit_sim.py`（本项目移动止盈的唯一实现）保持同一套假设：跳空按开盘价成交、跌停封死卖不掉要顺延、一字板买不进要剔除。要验证退出假设请走它，别在别处重算一套。

十、把阶段当仓位开关（第二道预注册）

上一节只证到「阶段性条件收益 +0.8~1.7 个点」。但条件收益 ≠ 能靠它赚钱 —— 从统计到可执行规则中间还差三件事：① 换仓成本 ② T+1 落地（当天收盘定的阶段，第二天才能动仓位）③ 对照基准该是谁。本节把这三件补上，直接回测一条真规则：高潮 满仓 / 冰点、回暖、退潮 空仓。
标的仍是全市场等权收益（不是个股，本项目不出票）。
预注册判据（跑前写死）：P1 扣换仓成本后日均收益高于恒满仓；P2 前半段与后半段超额同为正；P3 按日 block bootstrap（block=21 天、2000 次）「日均可超额为正」的比例 R3 ≥ 0.95。三条全过才叫「能靠它赚钱」。
另有一条单列的 P4（风控价值）：把仓位压低本来就会让回撤变小 —— 不比「同等回撤下随便下注」就是循环论证。固定仓位对照线取 w ∈ {1.0, 0.75, 0.5, 0.25, 0.0}，不做任何判断。

10.5　这一节说明什么

结论：四条路径（赚收益 / 降回撤 / 反向规则 / 退潮离场）
为什么上一节那个 +1 个点会消失。这里测的是用全市场信号去择全市场仓位，本质是「用市场预测市场自己的波动」—— 信号那一点信息，要被自己的日常波动稀释掉。真正该做的是拿阶段去调节某个具体选股池的仓位（跨口径），但那需要那个池重走四道验证（无未来函数 / walk-forward / 随机对照 / 退出可兑现），不能拿这张表直接外推。
那这一节的价值在哪。它是否定性证据：把「龙道诀可以当仓位开关」这条路正式验死了，省得后面再花时间试。同时它钉住了一件事 —— 由条件收益到可执行规则之间，隔着「成本、落地时点、对照基准」三道坎，每一道都能让一点点 edge 归零。

保留的用法还是上一节那句：四阶段当温度计（看环境），不当选股器、也不当仓位开关。

十一、龙道诀候选 · 出票闸

前面三道检验说的都是「不行」，但它们验的不是同一件事。第九节验的是阶段能不能预测全市场（高潮可以）；第十节验的是能不能当仓位开关（不行，日均超额 −0.065pp）；本节验的是第三件事 —— 能不能据此选出一篮子票。
做法是把它做成一条正式通道：候选域（当日收盘封涨停的全集）→ T+1 开盘入场 → 项目既有移动止盈出场（−12% / +6% / 3% / 20 日，一个参数都不扫）→ 五项闸门。过闸就出名单，不过闸就是 0 票。
★ 关键的不同：入场价用 T+1 开盘（信号日收盘价作为成交价不可兑现），这也是前面几道检验没做齐的一环。

十二、使用边界

风险提示：本页是方法论科普 + 情绪周期定位，不构成任何买卖建议。龙头战法波动极大，连板梯队本身就在告诉你风险：六成以上的二板走不到三板。
  • 第五节给的是「这个形态今天出现了」的观察名单，不是个股推荐、不给买卖点位。它能不能变成可执行规则，看第④道 —— 第④道「退出可兑现」过了相对判据 —— 可实现口径胜率只比同阶段基线高0.4pp（这个量级属噪音），但扣掉双边成本后净均值仍为负：所以它仍然不是一条能执行的规则，只是「比乱买略好一点」。
    而且这不是某一个形态的问题：把 4 阶段 × 6 连板桶全过一遍，24 格里扣成本后净均值为正的有 0 格。
  • 所有分位只用截至当日的滚动窗口，不含未来数据；这是能做到的事，但历史统计 ≠ 预测。
  • 数据读到哪天就写到哪天。若显示「无法自检」，就是真没读到，不用估计值补。
