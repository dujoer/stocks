  • 判定按序：退潮 → 高潮 → 回暖 → 其余落冰点（有兜底，不会留空档）。

    • 回暖：涨停家数分位 ≥40 且（高度分位 ≥50 或 涨停家数分位 ≥60）
    • 冰点：以上都不满足
  • 分位样本不足 10 天 → 显示「样本不足」，不猜。

表里的规律（可核，不是解释是数据）

  • 越低位的票越接近「扔硬币」：首板 胜率 52.2%; 二板 胜率 55.0%
它靠什么站住（前三道自检，缺一不可）
  • ① 随机对照：同一天、同等数量，从全市场任意股票里随机抽 200 次，K=1 胜率的 95 分位是 52.7%（中位数 50.3%）；这一形态是 73.2% —— 过了（固定种子，可复现）
  • ② 同阶段对照：同一个情绪阶段里，全部涨停票的 K=1 胜率是 53.4%，这一形态是 73.2%，超额 +19.8pp —— 说明不是「阶段本身在托底」。
  • ③ 样本外（walk-forward）：前半段挑出的 冰点 / 四板 放到后半段（样本外）胜率 80.0%（n=25），仍不低于后半段最优 70.3% —— 结论站得住
但这三条只说明「历史上真的发生过」，不说明「能赚到」：第④道「退出可兑现」已补做，结果是没过 —— 换成买得到、卖得掉的打法，胜率 25.5% 反而低于同口径基线 32.5%（-7.0pp）。详见第六节。
看胜率的同时必须看「中位」和「最差」：K=5 均值 +7.25% 但中位只有 +1.98%、最好 +61.24%、最差 -26.66%。
意思是：多数时候赚的就是这点中位收益，真正把均值拉高的那批（最好那只 +61.24%）不是常态 —— 拿均值当预期收益会高估自己。最差那一列才是仓位管理的依据。

归因

可核的部分（数据直接给出的）：
  • 该形态 K=1 胜率 73.2%，比同阶段全部涨停票（53.4%）高 +19.8pp，比同天全市场随机抽票的 95 分位（52.7%）高 +20.5pp。
  • 样本 56 个、横跨 35 个交易日 —— 不是撞在单日上的偶然。
  • 三个持有期（1 / 3 / 5）都优于各自对照，不是只在某一个持有期上亮眼。
不可核的部分（如实标注，不编）：它为什么涨、题材是不是真的、游资在不在里面、明天会不会直接一字开 —— 这些本地数据衡量不了。日K 只能告诉你「过去这个形态后续大概率涨」，不能告诉你「这次为什么涨」。任何把行情归因到某条消息、某个概念的说法，都请自己核，本页不代劳。

  • 出场规则吃掉 17.9pp：60.7% → 42.9%。−5% 这条止损线对四板票来说太近了，基本是日内噪音就会打掉 —— 样本里 37/51 笔是「止损」出场，中位收益正好停在 −5.00%。
  • 入场假设再吃掉 17.4pp：42.9% → 25.5%。封板价买不到，只能次日开盘接；另有 5 个样本（8.9%）次日直接一字封板、根本买不进，被剔除。
  • 两处合计 35.2pp：60.7% → 25.5%。这就是「纸面胜率」和「真能拿到的胜率」之间的距离。
关于第 ⑤ 行，先把话说死：去掉止损后是 49.0%，看着比第 ③ 行好很多 —— 但那是在同一份数据上挑口径，正是红线里「不许挑最好看的那个窗口」要拦的事，而且它的对照基线也得用同样口径重算才算数。本页不据此修改方案。真要改（比如放宽止损），必须重新走一遍 walk-forward 和随机对照。
第④道的判据（写出来，方便被打脸）：拿最保守口径（③）的胜率，去比同口径基线（④）。高于基线 = 过；不高于 = 不过。此处 25.5% vs 32.5% → 不通过。
另有两点诚实交代：本节模拟的是全仓一次性了结，下面方案里「跌破 5% 先减半」是分批口径，未单独模拟；持有期按该票自己的交易日数，停牌会拉长自然日跨度。

以下是纸面推导（第④道通过之前，只当记录看）

这条方案是这么推出来的
  • 触发：情绪阶段判定 = 冰点，且当日收盘封涨停、连板数 = 四板。两条同时满足才进名单。
  • 买入假设：以当日收盘价成交。⚠ 这是简化假设 —— 真实打板要排队，可能封不上、也可能高开走，实际成交价高于收盘价；本页所有胜率都建立在「能成交且成交在收盘价」上，这一条没有单独验证。
  • 持有期：K=5（这个形态在该口径上均值 +7.25%、胜率 60.7%）。K=1 胜率更高（73.2%）但 均值只有 +3.67%，属于快进快出；两种口径差别很大，别混着用。
  • 仓位上限（由历史最坏情况反推，不是拍的）：本形态 K=5 的最差是 -26.66%。按单笔亏损不超过本金 1.5% 的纪律，单票仓位 ≤ 5.6%（换成 K=1 口径，最差 -10.19% → 单票 ≤ 14.7%）。取更小的那个。
  • 退出：跌破买入价 5%（由 K=1 最差的一半反推）减半，继续跌破再走；或持有满 5 个交易日时间止损；或情绪阶段转退潮 / 高潮时了结 —— 三选先到者。⚠ 这条线是从历史极值推的保守线，不是优化出来的最优解；第④道实测下来，正是这条线把胜率吃掉的。
  • 明确不做：冰点期去做首板 / 二板（K=1 胜率 52.2% / 55.0%，基本就是扔硬币，超额接近 0）。
结论：这一节的东西现在不能执行 —— 四道自检里 ①②③ 已过（无未来函数 / walk-forward / 随机对照），第 ④ 道补做后不通过。按红线，四道不全过就不出票。第四节「胜率最高的形态」作为历史统计规律仍然成立（那是真的），但「按上面这套规则去做能赚钱」这个推论不成立：换成买得到、卖得掉的打法，它的胜率反而低于同阶段随便买涨停票。
模拟口径与 `_exit_sim.py`（本项目移动止盈的唯一实现）保持同一套假设：跳空按开盘价成交、跌停封死卖不掉要顺延、一字板买不进要剔除。要验证退出假设请走它，别在别处重算一套。
