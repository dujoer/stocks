做T池 · 大盘环境门控样本外验证

面板 93,331 行 / 196 个交易日（2025-11-26 ~ 2026-09-02）｜ 真选股层 = 每日横截面按先验集取前 10%（生产 A 档口径）｜ 收益 = 线上现行做T逐笔模拟（反T：支撑上方 2% 进 / 1.2×ATR 目标 / −6% 止损 / 5 日到期，未成交记 0）｜ 显著性 = 按日 block bootstrap 800 次
一句话结论：本页验的是做T场景下那张共用表 ENV_RULE（强势 1.0 / 震荡 0.8 / 弱势 0.55 / 破位 0.0）的地基。 强势档 edge +0.40 pp（逐日平衡，95% 区间 [-0.73、+1.65]，bootstrap 通过率 70%） ；反推的相对系数（归一强势 = 1）：强势 +1.00、震荡 +0.80、弱势 +1.50、破位 +0.07。 乍看之下弱势（+1.50）比强势（+1.00）还高，四档点估计也全是正的；但本页后面的检验显示：这些点估计之间的差距，全部落在同一条噪声带里 —— 95% 区间无一例外跨 0、R3 通过率只有 48%~78%（远低于 95% 门槛）、反推系数的相对区间宽到 ±3 量级。所以本页做不出「哪一档该给几折」的结论，只能判「不可判」。本页结论独立于主升精选 env_gate —— 那是日线持有 20 日场景，这里是日内做T场景，两者共用同一张表但必须分别验证；也正因为如此，不能把主升的二值门控（强势开仓、其余空仓）照搬过来。

做T的未成交记 0（空仓等待是策略的一部分）。若某档 edge 明显高于其他档，但成交率也明显更低，那这个 edge 是「少出手」造成的，不是「选得准」——真实账户里底仓一直在，不做T的日子是有机会成本的，本口径没记这笔账。所以判定时同时看全样本均值与成交后条件均值。
一个反直觉的观察（只记录，不据此改规则）：现行 ENV_RULE 给破位档 0.0（完全空仓），但成交率诊断显示破位档的未成交占比最高（32%）、而成交后条件均值也最高（+1.68、条件胜率 54%），反而高于强势档的 +0.60 / 43%。也就是说：破位日里真成交的那部分做T，看起来比强势日做T更赚。但破位只有 25 个信号日、成交样本更少，且全样本口径下它的 edge 只有 +0.03（95% 区间 -1.5616705390815735 ~ 2.055094780676334，跨 0）。两个口径排序相反 = 样本量不够支撑任何结论，因此本页不建议把破位从 0.0 放开，只把它作为一条待积累样本的观察项记在这里。

七、结论与局限

判「不可判」—— 做T池的 ENV_RULE 折数（1.0 / 0.8 / 0.55 / 0.0）在样本外分不出差别，任何改法都还没有证据支持。
四个档的 edge 点估计虽都是正的，但 95% 区间全部跨 0、R3 通过率只有 强势 70% / 震荡 66% / 弱势 78% / 破位 48%（远低于 95% 门槛）；反推系数的相对区间宽到 ±3 量级（毫无分辨力）；环境分连续分位非单调（1.5 分与 2.5 分高、2.0 分最低、4.5 分为负），是噪声的形状而不是信息的形状。
因此：做T池保持现行 ENV_RULE 原值不动，也不套用主升精选的「强势开仓、其余空仓」——那是日线持有场景验出来的，做T是日内场景，且本页点估计显示弱势档+1.50 反而高于强势 +1.00，照搬会把做T做反。
  • 本页只验做T场景，与主升精选 env_gate 的结论不能互相套用；两者共用同一张 ENV_RULE 表，若要改系数须分别取得各自场景的样本外证据。
  • 口径对齐生产：环境分用生产 env_score = 0.45×指数分 + 0.55×market_profile core 的 composite；core 没有落盘的信号日退化为纯指数分，本页对这类日的标签可能与实际执行的 composite 标签不同（生产执行用 composite）。
  • 不是胜率提升器：edge 是相对「同日全票」的增量，不是绝对胜率。做T的未成交记 0，所以「空仓等待」在本口径下既不算赚也不算亏 —— 空仓的机会成本没有计入。
  • 面板时间窗口有限：2025-11-26 ~ 2026-09-02，共 196 个交易日；分到四档后每档只有个位数到十几日的信号日，bootstrap 区间必然很宽，这是真实的不确定性，不是精度问题。
  • 本页只验做T场景，与主升精选 env_gate 的结论不能互相套用；两者共用同一张 ENV_RULE 表，若要改系数须分别取得各自场景的样本外证据。
  • 所有数字由 quant/_tplus_env_gate.py 重算得出，种子固定（20261003）、bootstrap 800 次；原始结果落 quant/_tplus_env_gate.json。
