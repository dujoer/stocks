参考视角 · 点击展开
口径：从做T池中筛出相对强度跑赢大盘的标的（20 日超额 ≥5pp 或均线多头排列）。 「强势」= 20 日涨幅 − 上证 20 日涨幅（pp）；当前基准（上证 2026-11-13）20 日 -2.20%。
为什么单独看：做T池里的多数票是「区间横盘」，靠波动赚差价；强势股则是「趋势中回踩」—— 买在回踩、卖在再创新高，赚的是趋势 + 波动双击。两者操作纪律不同，混为一谈最容易做反。
强势股做T纪律（只做多、不逆势）：① 只在回踩 MA10 / MA20 不破时低吸，不追突破当天的冲高； ② 反弹到前高附近先减一半；③ 收盘破 MA20 或跌回买点 −5% 无条件离场；④ 20 日超额 >45pp（表内红色高分）视为高潮段，只减不加。
分档：强势多头超额 ≥5pp 且 MA5>MA10>MA20>MA60 多头排列 —— 趋势最完整，回踩即是买点； 强势整理超额 ≥5pp 但均线未完全多头 —— 强势中继，等均线收敛； 强势回调超额仍高但已跌破 MA20 —— 回调未确认结束，不参与，等重新站上再看； 温和偏强超额 0~5pp 且站上 MA20 —— 强度一般，当普通做T标的处理。

口径：做T池中近 10 个交易日上过龙虎榜的标的，按累计净买额排序。上榜 = 资金关注度与分歧同时放大， 往往对应振幅扩张、流动性充足——正是做T需要的环境；但席位性质决定方向：
怎么用（三看法）：① 看净买方向——累计净买为正 = 席位整体在吸筹（正向共振，做T容错率高）； 累计净卖为负 = 派发中，做T极易被闷杀，评分已被扣分。② 看游资等级——「高」= 一线游资参与， 波动大、节奏快，只能做「回踩买」不能做「追高买」；「低」或有机构专用席位 = 结构更稳，适合网格。 ③ 看分歧度——买前买后金额同时巨大（对倒特征）= 主力在对敲出货，直接放弃。
风险提示：龙虎榜是T 日盘后数据，T+1 才能动手；上榜股次日高开跳水的概率显著高于平常， 务必等回踩、不追首日冲高，仓位减半执行。本板块合计累计净买 5.83 亿元。

判定口径：箱体较宽（>48%）或有趋势斜率（|MA20 斜率| >3.2%）—— 属于宽幅震荡或带趋势，不适合机械挂单。
操作方式（几日一循环）：不求日内。回落至支撑位（箱体下沿与 MA20 的较高者）附近 0~2% 区间分批买；反弹至箱体上沿附近 0~2% 区间分批卖；一轮 3~7 日。 需要每日跟盘判断支撑是否有效，不做无脑挂单；趋势向下时宁可空仓等。
停止条件：破止损价无条件离场；MA20 下穿 MA60 或箱体下沿被放量击穿 → 停做T。

方法论：顶级机构如何做T

1. 网格交易法——在预设价格网格上机械高抛低吸，不预测方向，赚取波动本身。前提是标的处于区间震荡且波动率充足。 2. 均值回归——价格围绕箱体中枢（机构成本区）往复，偏离越远回归动力越强。 3. 底仓 + 卫星仓——底仓不动（吃趋势/分红），仅用卫星仓反复做T摊低成本；A股 T+1，做T必须先有底仓。 4. 波动率套利——日振幅/ATR 越大，单次做T的价差空间越大。 5. 相对强度增强（强势股）——只做「回踩买」，不做「逆势承接」，趋势方向与做T方向一致时胜率最高。 6. 龙虎榜跟踪——席位净买为正向共振，净卖为派发信号，用于校验而非替代结构判断。
候选来源（三源并集，逐只标注）： 机构底仓公募≥3% 或 社保/养老/年金/险资/汇金/证金/QFII ≥2 家（季报口径，箱体下沿支撑最强）； 龙虎榜近 10 交易日上榜且累计净买为正 或 ≥2 次（资金关注度 + 流动性天然充足）； 强势20 日超额 ≥5pp 且站上 MA20（趋势票，只做回踩）。 多源共振（同时命中 ≥2 条）优先级最高。
纪律：破箱体下沿无条件清仓；单次做T亏损 ≤ 总资金 0.5%；不追高、不满仓滚动。
评分机制（v6 · 先验固定因子集 · 域内横截面分位）： 做T分 = 下列 9 个因子各自取「当日域内横截面分位」后等权平均 × 100，无权重手调、无因子筛选 —— 因子方向全部由做T的经济逻辑预先给定，因此全期都是干净样本外。分数是相对位置（今天在池子里排多前）， 不是绝对适合度，故不会随行情漂移。分档按分位：A = 当日前 10% / B = 前 25% / C = 其余； 命中解禁 / 计划减持窗口的票直接进 D（风险否决·仅跟踪），不参与出池。
