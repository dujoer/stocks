三连阴 · 分档出票核验

本页核验一个具体问题：页面写「★ 观察档（跌 8~12%）两半同向跑赢基准，本期主推」——这句话成立吗？
① 原结论的对照是 该档 vs 全体三连阴母集，而母集里含它自己 —— 这是「子集对母集」，不是等量对照（R1），且原结论没有给任何显著性区间。
② 本页按全项目统一口径重算：逐日平衡 edge（该档逐日均 − 同日对照逐日均）、按日 block bootstrap {boot} 次算 R3、留一法、前/后半、跨步长敏感性。
③ 双对照并列给出：母集对照（含自己，偏向低估）与 等量对照（同日非本档 = 「买这档 vs 买别的三连阴」的真实差异）。出票许可取更严的等量对照。
原结论原样保留（见第一节），不删改历史判定；两者不一致时以本页为准，并写明原因。
⚠ 结论：★ 观察档本期不出票（宁可不选）

原结论「两半同向跑赢基准」在前后半上是 前后半同向（前半 — / 后半 —）。；但「跑赢母集」与「edge 显著为正」是两件事 —— 原结论只答了前者。
不写「改个阈值就能用」的建议，只记录已算出的事实。

一、原结论（原样保留，不删改）

`_3yl_lab.py` 与观察池页面写的是：★ 观察档（跌 8~12%）两半同向跑赢基准： T+1 涨 54.0% / 胜率 47.7% / 期望 +0.43%（基准 48.7% / 44.3% / +0.01%），本期主推。
这是全样本摊平对比（把该档所有信号堆在一起比均值），不是逐日平衡。 对照「基准」= 全体三连阴，含观察档自己。方向性参考有价值，但它不等于 「买观察档能跑赢同一天买其它三连阴」，也没有给置信区间。

八、口径与局限

  • 信号：收盘连续 3 日下跌 + 近 3 日无停牌跳空 + 量 > 0；累计跌幅 = 1 − 信号日收盘 / 三连阴开始前一日收盘（与 build_3yl.scan()、_3yl_lab 一字不差）。
  • 退出：T+1 开盘买入 / 止损 5% / 止盈 8% / 持有 5 日；同日双触保守记止损。
  • 回测窗口 2025-11-04 ~ 2026-09-22；域 = 全市场离线日K（剔 ST / 退市 / 北交所 / 无市值）。
  • 本页只判定现有分档规则有没有超额，不做规则改良：edge 为负不代表反向做能赚钱， 是不该拿它出票。
  • 生产 scan 还叠了「现价 ≥2 元 + 20 日均额 ≥2000 万」两条流动性门槛（build_3yl 的 PRICE_MIN / AMT_MIN）。本页面板未叠这两条 → 结论偏宽松，属放宽而非收紧， 不会把不合格的档说成合格。
