🚧 关键时间红线（不可逾越）

1. 板块强度窗口：T日 20:00–21:00 全量更新；若漏跑，必须在 T+1 09:15 之前补跑——开盘后 data_sector 只返回当日最新快照，历史不可回溯，漏一天即永久断档。
2. 心理雷达：每日必做，盘后 ~21:00 产出，统一走 python quant/build_psychology.py --date D（节假日 --next N）。旧的「复制上一期 HTML + 精确字符串替换」模板法已废弃——锚点失配会静默残留旧数据，是该子系统历史反复停更的根因。
3. 推送外网：_push_lhb.py 必须 dangerouslyDisableSandbox=true 运行，否则被沙箱 SIGTERM 且无输出。
4. 推送后校验：GitHub Pages 有 ~1 分钟构建延迟，新建/改动页首测常 404，复测即 200；务必 curl 抽检关键页，且不可信 |tail 截断的推送日志。
