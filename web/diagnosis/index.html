方法纪律

  • 先证伪，再打分：四道独立否决走完，硬否决成立即出局，不再看分数。
  • 否决力度 = 证据强度 × 信号方向：硬数据看空 = 出局；推理级（归因 / 解读）只降档。
  • 两段式打分：B 组（机构主导 / 订单可验证 / 瓶颈环节）不可回测 → 只降档、不给分；A 组（趋势 / 位置 / 量价 / 换手）可回测 → 出 0 / 0.5 / 1 子分。
  • 口径三陷阱：负基数不读同比；TTM 扣非为负时扣非 PE 不适用（须写「完全失真」）；数据商 _Q 单季字段须自算交叉验证。
  • 三周期分设结论，禁止笼统的「买 / 不买」；每条结论带数字门槛 + 对账日。
  • 只做研判、不给买卖结论；产出的是「可被证伪的判断清单」。
