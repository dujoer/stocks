一、"松发模型"的四条必要条件

① 重估事件：资产重组 / 借壳 / 重大资产置换 / 主业切换完成，或明确转型预期。估值锚被重写（如陶瓷→造船）。
② 行业景气：所处行业处于上行周期（造船、风电海工、半导体国产替代、军工、有色反转等），利润能真实兑现。
③ 小流通盘：流通市值偏小（经验值 < 100 亿），筹码易被资金推动，弹性大。
④ 相对低位：价格距 52 周高回撤大、或 YTD 仍为负、刚从底部反转——即"重估尚未被市场充分定价"。
与松发本质不同点：松发已是高位（距52周高仅-2.9%）。本框架专门找"逻辑相似、但仍在低位"的标的，即条件④更严格。

二、适用板块池（板块与规则）

创投 / 并购重组政策受益 半导体国产替代（设备 / 代工） 风电 / 海工装备 军工（材料 / 整机） 有色 / 化工景气反转 困境反转（单季净利同比转正） 央企 / 地方国资资产注入
筛选方法：westock tool_filter 的 preset（turnaround 困境反转 / main_inflow 主力流入 / low_pb 低市净率）交叉，再用 data_quote 验证流通市值与 52 周位置。

三、低位建仓的量化触发规则

维度触发条件（低位买点）反面（回避）
位置距 52 周高回撤 > 30%，或 YTD < 0距高点 < 10%（已充分定价）
筹码回踩 MA60 / 布林下轨不破，缩量企稳高位放量长上影、主力净流出
资金20 日主力净流入转正，且散户净流出（筹码向主）散户净买入、融资暴增（派发）
动能RSI 自超卖回升但仍 < 55，KDJ 的 J 由负转正J > 100 极端超买
事件重组/注入落地但未大涨，或景气数据持续验证利好兑现即见光死
