底部反转池 v6 · 分档出票核验

本页回答一个问题：页面上那张「走前验证」表打出来的数字，是不是你真正会买的那批票？ 生产实际出票 = 旧硬门槛 ∩ 阶段底部＋启动证据 ≥2 条 ∩ 组合分属于域内前 10%（A 档）， 2026-09-30 只出了 52 只；而页面原表第 ④ 组有 2159 条。不是同一批票。
本页按生产真实出票口径在全市场日K上重建面板（逐日逐票复刻每一道闸门）， 用主升/做T 门控同一套方法重新判定：逐日平衡 edge + 按日 block bootstrap + R3 + 留一法 + 前后半 + 步长敏感性。
结论：现行出票条件（A 档）拿不出「跑赢随便买」的证据，本期不出票。
A 档相对同日全市场域的逐日平衡超额为 -0.238 pp（R3 29.9%，留一法区间 [-0.391, -0.052] 全为负）；另一组步长（step3）为 -0.025 pp —— 符号翻转。绝对胜率 63.41% 看着不低，但同一对照（随便买）的胜率是 62.95%，两者几乎一样；而平均收益 -0.23% 明显低于对照的 0.01%（赢面小、亏面大）。
按红线「宁可不选，不能乱选」，本期不按 A 档出票，列表照列但不作买入依据；B 档（组合分 10~25%）点估计最正（+0.763 pp，后半 +1.351 pp），但 R3 跨步长 95% / 85% 未稳定过线，同样只记为待验证。

二、为什么页面原表不能直接用（子集 vs 母集）

原表 ① 深跌域全体 n=13801 / 胜率 59.9% ，④ 本页采用 n=2159 / 胜率 65.0% —— ④ 是 ① 的子集（先过旧硬门槛、再叠闸门）。子集相对母集的绝对胜率天然偏高，这不是超额； 且两者样本量比 6.4 : 1，直接违反 R1 等量对照（要求 ≥0.5），也没有任何显著性区间。 本页改成逐日平衡＋同日对照后，同一条闸门（不看组合分那组）的超额只有 +0.237 pp，不是 +5.1pp。

七、复刻是否正确（自检）

九、局限与口径声明

  • 样本只覆盖 2025-09 ~ 2026-09 一段行情；反转类策略与市场状态强相关，本页结论不声称适用于所有行情， 只声明「在这段样本内拿不出正超额 → 不出票（宁可不选）」。
  • 阶段底部用即时检测复刻（生产是「锚定 + 版本化」写盘）。锚定只影响谷底值是否随行情漂移， 对本页的逐日平衡比较不改变方向；若要完全一致需按日回放 anchor，属另一个工程。
  • A 档只有 34 个信号日 / 646 笔 —— 样本本身就小；这正是本页判「不可判」而不是判「有效」的原因。 要么放宽闸门攒样本，要么等行情走出来，都不该在样本不足时出票。
  • 退出生效参数沿用全项目统一口径：−12% 硬止损 / +6% 激活移动止盈 / 回撤 3% 跟踪 / 满 20 日强平。
  • 本页只判定「现有规则有没有超额」，不做规则改良：B 档点估计最好也只列为待验证，不代表改用它就能赚钱。
