这张表怎么用（操作路径）

第 1 步 · 先看「阶段」
底部区 = 已经止跌、仍在谷底附近横着；启动 = 已突破谷底之后的平台上沿，但还没走远。 只要出现「下跌中 / 已脱离」就不会进这张表（前者还在创新低，后者已经涨超谷底 15%）。
第 2 步 · 认牢「谷底」这个数
谷底价是结构止损的基准，锚定后不再天天改：后面写着「已锁 N 日 · 第 v 版」。 跌破谷底 3% 意味着底部结构失效 → 无条件减仓，不做「再等等」。
第 3 步 · 先看「平台上沿」，再看 T1 / T2
T1 = 谷底 + 本轮跌幅 × 0.382，T2 = ×0.618 —— 按本轮下跌段算，比按 52 周高算的目标近得多。 但股价会先撞上「平台上沿」（谷底之后形成的前高，见详情页），那是最近的真实阻力，到不了 T1 就先减一半。
第 4 步 · 退出纪律（唯一跨期稳定的部分）
买入等回踩，不追高。止损分两层：跌破谷底结构位先减半，跌到 −15% 全出； +8%~+10% 先止盈一半；单笔试仓 3–5%。实验室把止损/目标两半对照后， 宽止损 + 早止盈是两半同向的最优组合（−15% / +8% → 训练半 54.7% / 测试半 55.8%）， 而最紧的 −6% 止损只有 41.3% / 36.3%（因为前 10% 的平均最大不利偏移已达 −7.7%，贴身止损必被扫）。
⚠️ 诚实标注（必读）： 位置约束本身几乎是胜率中性甚至略负的——单独要求「贴着谷底」并不提高前向收益 （大样本走前消融相对各自半区基线 −2.5pp / −0.8pp）。它换来的是尾部风险下降（平均最大不利偏移收窄）， 也就是「不追高、不接飞刀」。真正稳定提供边际的是「已经出现回升启动证据」（同一消融 +2.0pp / +6.4pp）。 所以这套规则是风险控制 ＋ 证据确认的组合，不是「越跌越买」的反向交易系统。
仓位与红线： 单笔试仓 3%（可至 5%），按 −15% 硬止损折算 = 单笔最大亏损约 总资金 0.45%~0.75%。 总暴露乘当日仓位系数（广度 <35% → 0.4× / 35~55% → 0.7× / ≥55% → 1.0×）， 该系数只控 β、不改排序。反转策略靠「多次小亏换一次大赚」，退出纪律 > 入场筛选。 本页所有价位都是量化区间，非买卖建议。
