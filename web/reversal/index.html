第 1 步 · 看「档」决定能不能碰
A 档（本期 39 只）= 低位 + 小盘 + 资金正 + 技术双确认，是唯一可进入一档观察的； B 档（本期 59 只）= 边缘分，只监控、不建仓；C 档不计入本表。
第 2 步 · 用「20日主力」验证资金是否真进场
为正 = 资金已确认反转；为负或贴近 0 = 形态再好也降级看待，等资金转正再说。 5 日与 20 日同号 → 流入在延续；反向（20 日正、5 日负）→ 近期主力已在撤，警惕假反转。
第 3 步 · 用「距52高 / YTD」确认位置够低
距 52 周高回撤 ≥ 25% 才算真低位；YTD 仍大幅为负 = 尚未被修复，正是本池要的横截面分位逻辑（越未修复越好），而不是「跌得多就该买」。
第 4 步 · 用「买区 / 止损 / 目标T1」执行
不追高：等缩量回踩买区不破再试仓；跌破止损无条件离场，不抱「等反弹」； 到 T1 分批止盈。买区与止损由近期低点、MA20 与 ATR 推得，不是主观价位。
仓位与退出纪律（红线）： 单笔试仓 ≤ 总资金 3–5%；单笔最大亏损 ≤ 总资金 0.5%；A 档可分 2 批，B 档不建仓。 反转策略靠「多次小亏换一次大赚」，退出纪律 > 入场筛选——本页所有价位都是量化参考区间，不是买卖建议。
