高胜率候选池 · 分档出票核验

本页是「高胜率候选池」的出票合法性核验（逐日平衡 edge + 按日 block bootstrap + 留一法 + 前/后半 + 跨步长）。
① 生产打分满分 100 分，其中只有技术 25 + 位置 15 = 40 分在历史上可前推；资金/筹码/板块/龙虎榜/高管大宗都来自当日盘后快照与事件源，回测时不存在 → 记 0 降级。
② 因此本页 CORE 档 =「可得子分前 10%」，不是生产那批「全维 ≥68 的核心候选」；生产核心档是否真有超额，本页判 不可判（缺 60 分维度，无法复原）。
③ 但有一件事不用统计就能定：底池的数据本身是过期的——自 2026-09-17 起连续 6 期 MACD 快照逐字节相同、收盘价反查 35/35 只等于 2026-09-11（见第六节）。这是数据就绪问题，优先级高于一切策略优化。
⚠ 先说结论：高胜率候选池本期不出票（宁可不选）—— 底池是旧数据，不是策略问题
MACD 技术底池自 2026-09-17 起连续 6 期逐字节没有重扫（dif / dea / close 全同）；把冻结快照里的收盘价拿去日K 反查，35 / 35 只精确等于 2026-09-11。
也就是说，这几期页面上标的「当期候选」用的是一份 2026-09-11 的旧快照冒充当日数据 —— 直接违反「严禁用旧数据冒充当日」。
因此先修底池重扫，再谈胜率；在数据修好之前，本池候选不作任何买入依据。

八、退出回测的成交假设（同一批票，只改成交假设）

本页所有胜率/均值都用「移动止盈」口径结算，而这个口径本身依赖两处人为假设：
① 日内路径：旧实现假设同一根 K 线「先冲高（上移止盈线）→ 再回落（触发卖出）」→ 系统性乐观；
② 跳空：开盘已跌破止损线时，旧实现仍按「止损线价」成交，真实只能按开盘价成交（更差）。
只把这两处换成可兑现版本，CORE 档的绝对胜率就是 55.80% → 49.64%（-6.16pp） —— 本池原本就判「不出票」，修正后亏损面进一步扩大。

九、局限与口径声明

  • 可得维度只有 40 分，生产核心候选（全维 ≥68）的合法性在本页判「不可判」 —— 不是「没用」，是没法验。
  • 资金（20）/筹码（15）/板块（12）/龙虎榜（8）/高管大宗（5）在回测时不可得，按纪律记 0 降级， 因此本页总分上限 40，CORE 阈值是「前 10%」而非 68 分。
  • 退出生效参数沿用全项目统一口径：−12% 硬止损 / +6% 激活移动止盈 / 回撤 3% 跟踪 / 满 20 日强平； 买入价 = 信号日收盘（与生产「次日开盘」略有出入，属放宽，只会让结论偏保守）。
  • 本页只判定现有规则有没有超额，不做规则改良：负 edge 也不代表「反向做」能赚钱，只是不该拿它出票。
  • CORE 档样本 53 个信号日 / 1672 笔 —— 样本偏小，正是本页判「不可出票」而不是判「有效」的原因。
