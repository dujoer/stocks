📅 每日更新清单（SOP）

完整操作手册（数据口径、已知坑、校验清单）见 DAILY_UPDATE_SOP.html。下表为精简步骤，各子系统最新日期以本门户卡片为准。
1
① 拉取当日快照
用 westock-mcp 拉取 market_overview / board_hot / quotes / limitup / lhb / news，分别落盘到 quant 对应子目录的 {DATE}.json；再补 lhb 个股明细（分 3 批）。
2
② 高管增减持
tool_event(manager_sharechg) + data_quote → python quant\gen_exec.py --date {DATE} → python quant\build_exec.py --date {DATE}。T+1 口径，接口快照日为前一交易日。
3
③ 大宗交易
tool_event(names=block_past_30, limit=3000)（limit 必须给足，默认 500 会截断当日数据）→ data_quote 补涨跌幅 → python quant\gen_block.py --date {DATE} --src <事件落盘> --quotes <行情落盘> → python quant\build_block.py --date {DATE}。
4
④ 生成龙虎榜主看板
python quant\build_dashboards.py --date {DATE} → 重写 web/ 下各页面（会重建 web/lhb/index.html）。
5
⑤ 板块强度（必做 · 不可回溯）
拉 industry + concept 快照 → python quant\gen_sector_raw.py → python quant\run_daily_sector.py --date {DATE} --industry <绝对路径> --concept <绝对路径>。漏跑一天该交易日永久断档。
6
⑥ 心理风险雷达（按需）
按 web/psychology 既有 _build 范式生成 crowd-psychology-risk-radar-{DATE}.html 并入 web/psychology/index.html。数据内嵌在 _build 脚本内。
7
⑦ 刷新门户与总览
python quant\build_portal.py → python quant\build_sections.py → python quant\_apply_nav.py（统一导航自愈）→ 各卡片自动带出最新日期与新鲜度。
8
⑧ 校验与推送
合规扫描（产物内不得出现个人持有信息、账户盈亏、自下而上选股等敏感内容，关键词清单见项目约定）；python quant\_link_check.py 须 0 断链；经 GitHub Contents API 推送（python quant\_push_lhb.py）。
