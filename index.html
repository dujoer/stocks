📅 每日更新清单（SOP）

完整操作手册（数据口径、已知坑、校验清单）见 DAILY_UPDATE_SOP.html。下表为精简步骤，各子系统最新日期以本门户卡片为准。
1
① 拉取当日数据
用 westock-mcp 拉取 market_overview / board_hot / quotes / limitup / lhb / news，分别落盘到 quant 对应子目录的 {DATE}.json。
2
② 生成龙虎榜主看板
python quant\build_dashboards.py --date {DATE} → 重写 web/ 下 7 个页面（含导航 index.html）。
3
③ 板块强度（可选）
若当日行业/概念快照已落盘：python quant\run_daily_sector.py --date {DATE} --industry <file> --concept <file> → 刷新 web/sector-strength-* 与索引。
4
④ 心理风险雷达（可选）
按 market-trend 既有 _build 范式，用当日 westock 真实数据生成 crowd-psychology-risk-radar-{DATE}.html 并入 market-trend/index.html。
5
⑤ 刷新总门户
python quant\build_portal.py → 重建本页，自动带出各子系统最新日期与新鲜度。
6
⑥ 校验与推送
检查无外链/死链、JS 语法；经 GitHub 连接器推送 web/ 与 market-trend/ 至仓库。
